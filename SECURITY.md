# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues or pull requests. Use GitHub's **Report a vulnerability** flow in the repository Security tab to submit a private advisory. If that feature is unavailable, contact the repository maintainer privately through their GitHub profile.

Include the affected component or endpoint, impact, reproduction steps, and a suggested mitigation when possible. Do not include real user data or live credentials in a report.

## Scope notes

This is a portfolio prototype, not a production food-ordering service. Do not use real payment credentials, customer information, or production data. The food checkout and operations screens are demo UI; review `docs/demo-and-limitations.md` for current scope.
